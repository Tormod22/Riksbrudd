# Riksbrudd – prototyper

Statisk side. Ingen bygg nødvendig.

Deploy:
1. `npm i -g vercel` (én gang), deretter `vercel deploy --prod` i denne mappen, eller
2. dra mappen inn på https://vercel.com/new, eller
3. legg mappen i et GitHub-repo og koble det til Vercel.

Sider: `/` (forside), `/norge` (Norge 1986), `/dovre` (Dovre 1987 testområde).
